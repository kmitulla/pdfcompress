Übergabe–

Token in Paperless: oben rechts auf deinen Namen → Mein Profil → bei API-Token auf ↻ (erzeugen) → kopieren.
So funktioniert die Übergabe

API (empfohlen): Der PDF-Presser-Server schickt das fertige PDF direkt an Paperless (/api/documents/post_document/) – mit dem Namen aus der App als Titel. Es braucht keinen gemeinsamen Ordner. Die Adresse muss vom Server aus erreichbar sein, also z. B. http://IP-DES-THINKCENTRE:8000 (nicht localhost).

Ordner: Das PDF wird in den consume-Ordner gelegt, den Paperless überwacht. Hier steht der Pfad im Container. Damit die Datei auf dem ThinkCentre ankommt, muss der Ordner in der docker-compose.yml eingebunden sein (z. B. /DATA/paperless/consume:/data/consume) – Unterordner davon gehen ohne Änderung.

Ist die API eingerichtet, wird sie benutzt; ist sie nicht erreichbar, landet die Datei im Ordner. Werte hier haben Vorrang vor der docker-compose.yml – leeres Feld + Speichern = wieder der Wert aus der Compose.
